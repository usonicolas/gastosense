# Pruebas

Las pruebas usan el ejecutor integrado de Node.js (`node:test`), así que no requieren instalar dependencias.

```bash
npm test
```

## Qué se prueba en esta entrega

- Registro de ingresos y gastos con datos válidos.
- Rechazo de montos no válidos, tipos desconocidos y categorías vacías.
- Cálculo del saldo disponible.
- Resumen de gastos por categoría.
- Alerta de presupuesto al acercarse al límite y al superarlo.

## Plan para las siguientes entregas

- Pruebas de cada patrón de diseño que se incorpore.
- Pruebas de integración con la base de datos.
