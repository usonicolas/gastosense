# Patrones de diseño

Aquí se documenta cada patrón que el equipo implemente en el código.

Para cada patrón, incluir un archivo con:

- Nombre del patrón.
- Problema que busca solucionar.
- Justificación de su selección.
- Descripción de su aplicación.
- Componentes involucrados (archivos de `src/`).
- Beneficios obtenidos.
